## 💫 About Me

I work at the intersection of **molecular biology, sequencing data, and machine learning**. My research focuses on context-aware regulatory modeling: not just asking whether a motif exists, but whether the cellular context makes binding, accessibility, or regulation biologically plausible.

- 🔭 **I’m currently working on:** Developing computational frameworks for modeling Transcription Factor (TF) binding using multi-modal inputs (ChIP-seq, ATAC-seq, RNA-seq, and AlphaFold structures).
- 👯 **I’m looking to collaborate on:** Open-source Bioinformatics tools, specifically those involving genomics pipelines, structural biology, or machine learning applications in transcriptomics.
- 🌱 **I’m currently learning:** Advanced techniques in evolutionary bioinformatics and optimizing multi-GPU deep learning pipelines.
- 💬 **Ask me about:** The intersection of Microbiology and Data Science, why understanding gene regulation is the key to multi-omic research, and R/Python for biological data.
- ⚡ **Fun fact:** I can transition from a wet-lab environment (Microbiology) to a CLI-only Linux environment faster than a DNA polymerase can replicate a primer!

## 🚀 Featured Research Projects

| Project | Description | Links |
| :--- | :--- | :--- |
| **DuATTAC / ATAC Signal Predictor** | Dual-stream deep-learning model predicting continuous log-transformed ATAC-seq signal from DNA sequence and RNA-seq multi-gene context. *(Presented at COPM2026)* | [Repository](https://github.com/ipranjalisharma/DuATTAC) |
| **Context-Aware TF Predictor** | Six-branch late-fusion framework combining DNA sequence, k-mer density, AlphaFold graphs, RNA-seq, causal neighbors, and ATAC accessibility. | [Profile](https://github.com/ipranjalisharma) |
| **Causal Networks (DAG-DeepVASE)** | Genome-wide RNA-seq causal network inference using knockoff selection, MB-LASSO, and directed acyclic edge orientation. | [Repository](https://github.com/ipranjalisharma/Causal-networks-by-modified-DAG-DeepVASE) |
| **RNA-seq Automation Pipeline** | Automated reproducible workflow from quality control through downstream differential expression analysis. | [Repository](https://github.com/ipranjalisharma/RNA-seq-automation-pipeline) |
